# Sunnybotics Engineering

Work from my internship at Sunnybotics (Summer 2026), focused on firmware engineering, systems integration, and research for the Sunny Clean Bot solar panel cleaning robot.

## Projects

### SB_motor_driver
Motor driver firmware for the Sunny Clean Bot. Includes the Keya KYDBL4850-2E driver integration, telemetry pipeline, and the ongoing migration to ODrive S1 with CAN-based communication.

### sunnybotics-simulator
Virtual robot health simulator for the Sunny Clean Bot. Simulates operational data and fault conditions for testing and development purposes.

### COD_V3
Supporting firmware and control code.

### documentation
Lab validation protocols, motor driver evaluation research, ML data pipeline proposals, and configuration notes.

## About
Built and maintained by Arushi during a Summer 2026 internship at Sunnybotics. Primary focus areas: embedded systems, motor control, CAN communication, and data infrastructure for predictive maintenance.
